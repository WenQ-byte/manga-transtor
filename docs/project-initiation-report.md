## 一、项目使命

提供一个低门槛、可本地部署的漫画翻译工具，让用户通过“上传 → 翻译 → 下载”完成单张或多张漫画翻译，同时尽可能保留原始分镜、气泡轮廓、阅读顺序和视觉风格。

本项目不以“能生成中文图片”为唯一完成标准，而以以下四项同时成立为目标：

1. 原文检测和识别足够完整。
2. 原文字迹被安全擦除，人物、线稿、网点和气泡轮廓不被明显破坏。
3. 翻译结果保留上下文、人物语气、数字和专有名词。
4. 中文文字进入正确气泡，顺序正确、不越界、可阅读。

## 二、目标用户与价值

### 目标用户

- 希望阅读日语或英语漫画的个人用户。
- 需要快速评估海外作品的编辑或小型出版团队。
- 需要本地化原型、术语一致性和可复现流程的开发者。

### 核心价值

- 降低漫画翻译和排版的工具门槛。
- 将检测、OCR、修复、翻译和排版组织为一个可观察的流水线。
- 通过可插拔模型和回退链，在质量、成本与本地资源之间取得平衡。
- 用真实漫画案例驱动修复，而不是只在合成样例上优化。

## 三、当前范围

### 已交付

- 单张 JPG/JPEG/PNG/WebP/BMP 上传、进度查询、结果预览与下载。
- 多图全量校验、独立单图任务编排、总体/单图进度、取消与 ZIP 汇总导出。
- 日语/英语 → 中文。
- CTD、DBNet/ResNet34、CV 检测器。
- MIT 48px OCR、manga-ocr、PaddleOCR 3.x。
- CV 与 LaMa 双修复引擎。
- 气泡过滤、非气泡文字保留、拉丁标签保护。
- 气泡级整块翻译和 DeepSeek 页级上下文批量翻译。
- DeepSeek、OpenAI、DeepL、Google、MyMemory 后端与自动回退。
- 专有名词图形化管理和 JSON 导入。
- 横排/竖排中文自适应排版。
- 翻译质量告警、气泡几何回退和安全裁剪。
- React/Vite 中文前端与 FastAPI REST API。
- Windows 一键启动、手动启动与 Docker Compose 基础配置。

### 当前不在交付范围

- 章节级持久队列、批次历史、暂停和断点续跑。
- PDF、PSD、XCF 等出版格式。
- 用户账户、云同步、历史任务和团队权限。
- 气泡内人工校对、拖拽排版和文字样式编辑器。
- 漫画上色、超分辨率、视频翻译和浏览器插件。
- 对所有艺术字、开放式气泡和深色复杂背景作绝对质量保证。

## 四、工程原则

### 4.1 正确性优先于覆盖率

无法安全定位气泡时，允许缩小排版区域或跳过渲染，不允许为了“必须出字”而覆盖人物、跨越分镜或把多个气泡合成一个大块。

### 4.2 原图与清理图承担不同职责

- 清理图用于寻找没有原文字遮挡的气泡内部。
- 原图用于确认气泡轮廓、分隔线和视觉结构。
- 当清理图泛洪结果与原图边界冲突时，以原图结构证据为准。

该原则已经用于相邻气泡分组：即使清理后掩膜泄漏，只要原图中存在连续分隔轮廓，就禁止合并。

### 4.3 检测、擦除、翻译阈值必须解耦

OCR 置信度低不代表检测框和逐像素掩膜不可靠。MIT 路线允许低置信度但可读文本参与翻译，也允许有可靠检测掩膜的区域参与擦除，避免用单一 `0.5` 阈值同时造成漏译和残字。

### 4.4 模型可替换，失败可降级

检测、OCR、翻译、修复和渲染通过统一引擎接口获取。高质量模型不可用时必须有明确回退路径，并记录实际使用的后端和质量告警，不得静默退化。

### 4.5 真实案例必须转化为回归规则

每个已确认的系统性缺陷都应形成以下至少一项：

- 可复现的本地漫画案例。
- 不依赖外部网络的单元测试。
- 可观测的分组、后端或质量诊断信息。

### 4.6 视觉修改必须受边界约束

擦除掩膜和译文渲染只能影响授权区域。气泡轮廓、分镜线、人物和复杂纹理优先保护；模型生成结果必须按掩膜合成，不允许整块覆盖原图。

### 4.7 第三方许可证是发布门槛

移植自 `manga-image-translator` 的 MIT 推理代码按 GPL-3.0 管理。模型权重、在线翻译服务和其他依赖的许可证或服务条款必须在发布、分发或商业使用前单独核对。

## 五、当前架构基线

### 系统结构

```text
React/Vite 前端
      ↓ REST API
FastAPI 任务与文件服务
      ↓
可插拔漫画翻译流水线
      ↓
SQLite + 本地文件系统
```

### 流水线顺序

```text
detect
  → ocr
  → 置信度分流与非气泡保护
  → inpaint
  → bubble grouping（清理图内部 + 原图边界）
  → translate
  → quality assessment
  → render
```

修复位于翻译之前，使气泡分组不受原文字笔画阻断；原图边界否决机制防止修复后的轮廓缺口造成相邻气泡串联。

### 默认引擎

| 模块 | 默认/推荐路线 | 回退 |
|---|---|---|
| 检测 | CTD（MIT manga detector） | DBNet 或 CV |
| OCR | `mit48+mangaocr` | MIT48、manga-ocr、PaddleOCR |
| 修复 | 代码默认 CV；高质量推荐 LaMa | CV |
| 翻译 | 代码默认 Google；项目配置推荐 DeepSeek | 其他已配置高质量后端 → Google → MyMemory → 词典/原文 |
| 渲染 | PIL 气泡感知排版 | 安全扩展框 → 紧致框 → 跳过 |

## 六、关键质量机制

### OCR 与掩膜

- MIT 检测器每个 textline 保持独立 region，后续按气泡分组。
- `mit48+mangaocr` 只把完全空行交给 manga-ocr，不覆盖 MIT 已有输出。
- OCR 多边形、MIT 缓存掩膜、Otsu 笔画和注音扩展取安全并集。
- 竖排注音只向主文字左右扩展，横排只向上下扩展，避免误伤气泡轮廓。
- 刊头、拟声词和拉丁标签可标记为 `_no_erase`，原样保留。

### 图像修复

- 白色平坦背景采用受限局部背景填充。
- 复杂纹理采用 TELEA 或 LaMa 重建。
- LaMa 按相邻掩膜聚类后进行局部原尺寸推理，避免整页缩小导致小字残影。
- 修复后只在已知文字掩膜附近执行保守残影检测。

### 气泡分组

- 可靠掩膜重叠、文本方向、相邻性、组合紧凑度和面积膨胀共同参与合并。
- 原图长轮廓是合并否决条件，第一轮与二次合并均必须遵守。
- 贴合或重叠的同气泡文字列视为开放通路，避免被较远轮廓误拆。
- 链式吞并、稀疏大组和跨页泄漏均有上限保护。

### 翻译与排版

- 同一气泡整块翻译，DeepSeek 可一次处理整页编号段落。
- 已配置的高质量后端优先于免费后端。
- 译文过短、残留日文、数字缺失和免费/原文回退会产生质量告警。
- 竖排按原文列序组织，超长中文按语义和标点边界切列。
- 渲染必须被可靠气泡掩膜或安全矩形裁剪，防止文字越界。

## 八、风险与技术债

| 风险/技术债 | 当前措施 | 后续方向 |
|---|---|---|
| 艺术字和极小字 OCR 不稳定 | MIT48、小字放大、manga-ocr 救空 | 增加困难字体数据集和可选 OCR 模型 |
| 开放式/破损气泡容易泛洪 | 原图边界否决、面积/紧凑度上限 | 多源 watershed 与窄颈拆分 |
| 修复可能残留灰影或损伤边框 | 掩膜扩展、平坦背景重建、局部 LaMa、二次检测 | 建立残影与边框完整度指标 |
| 免费翻译质量不稳定 | 高质量后端优先、回退记录、质量告警 | 增加人工确认和重试入口 |
| CPU 推理较慢 | 模型缓存、局部 LaMa、可选 CUDA | 建立不同设备性能基线 |
| 模型权重部署复杂 | 可配置模型目录、自动搜索 | 模型下载脚本与校验清单 |
| 测试图片当前不入库 | 本地真实案例回归 | 建立可公开授权的小型回归集 |
