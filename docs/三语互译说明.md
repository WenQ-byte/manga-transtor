# 三语互译说明

系统支持中文、日语、英语之间的六种翻译方向。前端默认选择“自动检测 → 中文”，单图和批量任务均会把请求语言、实际识别语言、识别置信度、识别原因、实际翻译后端和失败回退写入任务元数据。

## 自动识别

自动识别以文字区域为单位比较候选。MIT48 结果包含平假名或片假名时优先判为日语；拉丁字母占主导时判为英语；不含假名的汉字文本按中文处理。纯数字、符号和信息不足的短文本会结合 PaddleOCR 置信度并使用 `MANGA_AUTO_SOURCE_FALLBACK` 兜底。自动模式只在确认日文后允许 manga-ocr 救空，中英文不会进入该模型。

## 翻译后端

DeepSeek 和 OpenAI 根据源语言与目标语言动态生成漫画提示词。DeepSeek使用同页编号上下文，过长页面安全分块，结构解析失败后进入逐条回退。DeepL、Google 和 MyMemory 使用统一语言映射；后端失败时继续沿用现有高质量后端、免费后端、词典和原文回退链。

词典同时记录源语言和目标语言，因此同一专名可分别配置中文、日语和英语译名。旧数据库启动时会自动增加 `target_lang` 字段，旧词条按“目标中文”迁移，不需要删除或重建数据库。

## OCR 与排版

中文和日语目标文本可按气泡形状与检测方向横排或竖排。日语字体候选覆盖假名、汉字、长音和组合字符；中文选择可用中文字体。英语目标统一安全横排，优先在单词边界换行，只有单个单词超出气泡宽度时才拆分，并使用独立字号/行距。现有气泡分组、擦除掩膜、非气泡过滤和渲染安全边界保持不变。英文掩膜按字符高度增加细笔画安全边距，中文采用更谨慎的膨胀。

默认 MIT48 与 manga-ocr 路线主要针对日语漫画；中文和英文默认路由到 PaddleOCR 的对应语言实例。任务状态会显示区域级识别语言、实际 OCR 引擎和渲染字体。极短对白、专有名词和中英混排仍可能需要显式选择源语言。

## PaddleOCR 推理设备

PaddleOCR 默认配置为 `MANGA_PADDLE_DEVICE=gpu:0`，也可使用 `gpu:1` 等编号选择具体显卡；设置为 `cpu` 可强制使用 CPU。项目使用 PaddleOCR 3.x 的 `device` 参数，不使用旧版 `use_gpu` 参数，并继续保留漫画竖排识别所需的方向配置。

使用 GPU 前，需要安装与本机显卡驱动、CUDA 和 cuDNN 相匹配的 PaddlePaddle GPU 版本。若当前 PaddlePaddle 没有 CUDA 支持、GPU 编号不存在、显存不足，或 PaddleOCR 在 GPU 上初始化/推理失败，对应语言模型会自动改用 CPU 并缓存复用。请求设备、实际设备和回退原因会写入任务的 `performance` 元数据；不会为每张图片或每个文字区域重复初始化模型。

GPU 的实际加速幅度取决于显卡、显存、CUDA 版本、图片尺寸、文字区域数量和低置信度回退次数，不承诺固定倍数。
