# 三语互译说明

系统支持中文、日语、英语之间的六种翻译方向。前端默认选择“自动检测 → 中文”，单图和批量任务均会把请求语言、实际识别语言、识别置信度、识别原因、实际翻译后端和失败回退写入任务元数据。

## 自动识别

自动识别使用整页 OCR 文本，不单独上传图片到识别服务。包含平假名或片假名的文本优先识别为日语；拉丁字母占主导时识别为英语；不含假名的汉字文本识别为中文。空文本、纯数字、纯符号和语言特征不足的短文本使用 `MANGA_AUTO_SOURCE_FALLBACK`，默认回退日语。

## 翻译后端

DeepSeek 和 OpenAI 根据源语言与目标语言动态生成漫画提示词。DeepSeek使用同页编号上下文，过长页面安全分块，结构解析失败后进入逐条回退。DeepL、Google 和 MyMemory 使用统一语言映射；后端失败时继续沿用现有高质量后端、免费后端、词典和原文回退链。

词典同时记录源语言和目标语言，因此同一专名可分别配置中文、日语和英语译名。旧数据库启动时会自动增加 `target_lang` 字段，旧词条按“目标中文”迁移，不需要删除或重建数据库。

## OCR 与排版

中文和日语目标文本可按气泡形状与检测方向横排或竖排。日语字体候选覆盖假名、汉字、长音和组合字符。英语目标统一安全横排，优先在单词边界换行，只有单个单词超出气泡宽度时才拆分。现有气泡分组、擦除掩膜、非气泡过滤和渲染安全边界保持不变。

默认 MIT48 与 manga-ocr 路线主要针对日语漫画。中文源图或复杂英文源图若 OCR 不稳定，建议显式指定源语言并使用 PaddleOCR。自动识别依赖 OCR 已经读出的文本，极短对白、专有名词和中英混排可能使用低置信度回退。
