# 个人总结

在本项目中，我围绕漫画图片智能翻译这一实际需求，参与完成了从需求分析、功能设计到系统实现和测试验证的完整过程。

项目让我认识到，AI 应用并不是简单调用一个模型接口。漫画翻译还需要处理文字区域检测、OCR 结果清洗、原文擦除、背景修复、气泡分组和中文排版等问题。尤其是在气泡分组和渲染阶段，单纯依赖识别结果容易造成相邻气泡误合并、译文越界或原文残影，因此需要结合图像几何信息和多级回退策略。

在工程实现方面，我了解了 React 前端、FastAPI 后端、异步任务、SQLite 存储和可插拔 AI 引擎之间的协作方式，也认识到批量任务不能盲目并发模型推理，需要优先保证结果稳定性。

本项目目前仍存在复杂图片识别不稳定、CPU 推理较慢、缺少历史记录和人工校对等不足。后续我计划继续完善对话式任务界面、单张重新翻译、GPU 加速和翻译质量控制，使系统从“能够运行的 MVP”逐步提升为“更适合实际使用的产品”。
