## 项目一句话介绍

本项目是一个基于 FastAPI 和 React 的漫画图片智能翻译系统，能够完成文字检测、OCR 识别、原文擦除、背景修复、气泡分组、上下文翻译和中文排版，并支持单图、批量翻译及专有名词库管理。
