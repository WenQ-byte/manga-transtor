# 用户手册

## 一、启动系统

双击项目根目录中的 `start.bat`，选择启动前后端。浏览器访问 `http://localhost:5173`。

## 二、单张翻译

1. 将 JPG、PNG、WebP 或 BMP 图片拖入上传区域；
2. 选择源语言，未知时选择“自动检测”；
3. 选择目标语言，默认是中文；
4. 点击“开始翻译”；
5. 等待检测、OCR、修复、翻译和渲染完成；
6. 在结果区域预览图片并点击“下载图片”。

## 三、批量翻译

一次选择多张图片后，点击“开始批量翻译”。页面会显示每张图片的等待、处理中、完成或失败状态。处理结束后点击“下载 ZIP”，即可获得成功图片、`manifest.json` 和失败说明。

## 四、使用专有名词库

进入“专有名词库”页面，可以新增角色名或作品名的固定译法，也可以搜索、修改和删除词条。批量导入时使用 JSON 数组，例如：

```json
[
  {"source": "例：Tanaka", "target": "田中", "lang": "en", "target_lang": "zh", "note": "角色名"}
]
```

## 五、常见问题

### 图片无法上传

检查图片格式、文件大小和文件是否为空。默认单张图片不超过 10 MB。

### 翻译速度较慢

首次使用可能需要加载模型。CPU 环境会比 GPU 环境慢，LaMa 和 MIT 模型也会增加处理时间。

### 结果中仍有原文

复杂背景、艺术字、拟声词或低清图片可能导致检测或 OCR 不完整。系统会尽量保留无法可靠判断的非气泡文字，避免误删画面内容。

### 翻译服务不可用

检查 `.env` 中的翻译服务配置和网络连接。系统会自动尝试备用服务，但免费服务质量和稳定性有限。
