# 源代码与部署说明

## 一、系统架构

```text
React/Vite 前端
        ↓ HTTP API
FastAPI 后端
        ↓
TranslationTaskManager 任务管理器
        ↓
TranslationPipeline 翻译流水线
        ↓
检测 / OCR / 修复 / 翻译 / 渲染引擎
        ↓
SQLite + 本地文件存储
```

## 二、核心流水线

```text
detect → ocr → inpaint → bubble grouping → translate → quality assessment → render
```

检测用于定位文字区域，OCR 用于读取文字；修复步骤先擦除原文，之后在干净图上寻找气泡内部区域。系统按气泡整体翻译，而不是简单逐行翻译，因此可以利用同一气泡内的上下文。

系统会过滤页眉、拟声词和装饰性文字，并用原图轮廓防止相邻气泡被错误合并。渲染时根据气泡形状判断横排或竖排，自动换行、分列和调整字号。

## 三、主要模块

| 模块 | 作用 |
|---|---|
| `backend/app/api` | REST API，包括翻译、任务和词库接口 |
| `services/task_manager.py` | 创建任务、异步执行、进度和结果管理 |
| `services/pipeline.py` | 编排完整翻译流程和质量信息 |
| `services/engines/detector.py` | CV/MIT 文字检测 |
| `services/engines/ocr.py` | MIT、manga-ocr、PaddleOCR 等识别引擎 |
| `services/engines/bubble.py` | 气泡过滤、分组和边界判断 |
| `services/engines/mask.py` | 文字掩膜和注音扩展 |
| `services/engines/inpainter.py` | OpenCV/LaMa 背景修复 |
| `services/engines/translator.py` | 翻译服务、术语和自动回退 |
| `services/engines/renderer.py` | 中文横竖排版和图片渲染 |
| `storage` | SQLite 数据库及本地文件存储 |

## 四、启动方式

### 一键启动

双击 `start.bat`，或运行：

```powershell
.venv\Scripts\python.exe start.py
```

### 手动启动后端

```powershell
.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --app-dir backend
```

### 启动前端

```powershell
cd frontend
npm.cmd run dev
```

前端地址为 `http://localhost:5173`，后端地址为 `http://localhost:8000`，接口文档为 `http://localhost:8000/docs`。

## 五、测试

```powershell
.venv\Scripts\python.exe backend\tests\test_app.py
```

测试覆盖单图和批量 API、ZIP 安全导出、任务串行隔离、OCR 适配、气泡分组、掩膜、背景修复、渲染、术语库、翻译回退和质量检查等内容。
