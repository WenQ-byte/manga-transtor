## 二、项目背景

日语和英语漫画中的文字通常分布在对话气泡、旁白框和复杂背景中。传统人工翻译需要先识别文字、擦除原文、修复背景，再重新排版，过程耗时且难以批量处理。因此，本项目希望提供一个低门槛的漫画图片翻译工具。

## 三、项目目标

1. 支持日语、英语和中文之间的基础翻译，重点服务日语→中文和英语→中文。
2. 自动完成文字检测、OCR、原文擦除、背景修复和译文渲染。
3. 尽量保留漫画气泡边界、横竖排版和阅读顺序。
4. 支持单图翻译、批量翻译、实时进度和结果下载。
5. 通过专有名词库提升角色名、作品名等固定术语的一致性。

## 四、交付范围

### 当前已实现

- 图片上传与格式、大小校验；
- 自动或手动选择源语言和目标语言；
- 检测、OCR、图像修复、气泡分组、翻译和渲染；
- 单图预览和下载；
- 批量任务、逐图状态、部分失败和 ZIP 导出；
- 专有名词库增删改查、搜索和 JSON 导入；
- 翻译后端回退和质量警告记录；
- SQLite 任务及词库数据存储。

### 当前不在范围内

- 用户账号、云端同步和团队协作；
- 完整历史任务检索；
- 人工校对编辑器；
- 从零训练 OCR 或翻译大模型。

## 五、验收标准

- 能够启动前后端并打开翻译页面；
- 上传合法图片后能够创建任务并显示进度；
- 翻译成功后能够预览和下载 PNG 结果；
- 批量任务能够显示成功/失败数量并导出 ZIP；
- 术语库可以新增词条并在翻译流程中使用；
- 非法格式、超大文件和无效语言组合能够被拦截；
- 后端自动化测试能够运行。

## 六、风险与应对

| 风险 | 应对方式 |
|---|---|
| AI 模型较大、首次加载较慢 | 提供 Demo 模式，并支持 CPU/GPU 配置 |
| 外部翻译接口失败 | 多翻译后端自动回退，并记录失败原因 |
| 气泡边界识别错误 | 使用清理图分组，同时使用原图轮廓进行否决 |
| 复杂背景擦除不理想 | 提供 OpenCV 和 LaMa 两种修复路线 |
| 批量模型并发导致状态污染 | 保留单 Worker 和流水线锁，采用串行推理 |
