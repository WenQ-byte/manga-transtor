## 5 经验教训及改进建议

### 5.1 经验

1. 先明确输入、输出和验收标准，再让 AI 参与代码实现，能减少无效改动。
2. 漫画翻译的关键不是单独的翻译 API，而是检测、擦除、气泡分组和排版之间的整体协作。
3. 每次修复真实样例后补充回归测试，比只追求单个样例效果更可靠。
4. 对 AI 生成方案进行反问和本地验证，是 VibeCoding 能够稳定交付的关键。

### 5.2 不足

复杂艺术字、深色纹理、开放气泡和极低清图片仍可能产生识别或修复误差；外部翻译服务需要网络和 API；CPU 推理速度较慢；当前暂无账号体系、完整历史记录和团队协作。

### 5.3 改进建议

后续优先进行 GPU/英文 OCR 性能优化、增加人工校对和历史任务管理，并继续以真实漫画样例优化日→中和英→中质量。AI 润色功能需要进一步增加风格约束、长度控制和失败保护。

**阶段性结论：**截至 2026-09-02，项目已经达到可运行、可演示和可解释的 MVP 验收状态；最终关闭结论由指导教师评审后填写。
