# ComicX 漫画多语言智能翻译系统用户手册

## 1 软件功能说明

ComicX 用于将漫画图片中的日语或英语文字翻译为中文，并生成保持原漫画结构的译图。系统会自动处理文字检测、OCR、原文擦除、背景修复、气泡级翻译和中文排版，同时支持人工修改译文、文字框、字体和擦除区域。

## 2 环境搭建

### 2.1 开发环境

| 类型 | 工具与环境 |
|---|---|
| 开发语言 | Python、JavaScript |
| 后端框架 | FastAPI、Pydantic Settings |
| 前端框架 | React 18、Vite 6 |
| 样式与动画 | Tailwind CSS v4、Framer Motion、GSAP |
| 图像处理 | Pillow、OpenCV |
| 检测/OCR | CTD、DBNet/ResNet34、MIT48、manga-ocr、PaddleOCR |
| 图像修复 | OpenCV TELEA、局部背景重建、LaMa |
| 数据库 | SQLite |
| 运行平台 | Windows；也提供 Docker Compose 基础配置 |

### 2.2 相关组件

系统使用本地 Python 包、前端 npm 包和可选 AI 模型。真实 OCR 模型首次运行可能下载模型文件；LaMa、MIT OCR 和外部翻译 API 均属于可选增强依赖。第三方代码和模型许可见项目根目录 `THIRD_PARTY.md`。

## 3 源代码、资源及数据清单

| 文件或目录 | 作用 |
|---|---|
| `backend/app/main.py` | FastAPI 应用入口和生命周期管理 |
| `backend/app/api/` | 翻译、文件和术语库 REST API |
| `backend/app/services/pipeline.py` | 翻译流水线编排 |
| `backend/app/services/task_manager.py` | 异步任务、编辑状态和结果管理 |
| `backend/app/services/engines/` | 检测、OCR、气泡、掩膜、修复、翻译和渲染引擎 |
| `backend/app/storage/` | SQLite 与本地文件存储 |
| `backend/tests/test_app.py` | 自动化测试 |
| `frontend/src/` | React 页面和交互组件 |
| `backend/data/fonts/` | 可选漫画中文字字体及许可证 |
| `backend/data/models/` | 本地模型权重目录，不提交到 Git |

## 4 源代码与数据导入

1. 安装 Python 依赖：`pip install -r backend/requirements.txt`；
2. 按需求安装 AI、LaMa、MIT 可选依赖；
3. 在 `frontend` 目录执行 `npm.cmd install`；
4. 复制 `.env.example` 为 `.env`，按需配置翻译后端、模型路径和运行设备；
5. 使用 `start.py` 启动系统。

## 6 系统要求

核心 Demo 模式可使用普通 Windows 电脑运行。真实 MIT/Paddle/LaMa 模型对内存、显存和磁盘空间要求更高；GPU 是否可用取决于显卡驱动、CUDA 和对应框架版本。翻译 API 功能需要网络连接和有效配置。

## 7 用户操作说明

### 7.1 创建翻译任务

1. 在底部输入区点击上传、粘贴图片，或直接拖入文件夹；
2. 系统按文件名自然排序读取文件夹图片；
3. 选择源语言和目标语言；
4. 可选 AI 润色风格或自定义提示词；
5. 提交任务，查看任务流中的逐图进度。

### 7.2 查看和下载

单张图片完成后会立即显示结果预览。用户可以单独下载、重新翻译或继续进入大图编辑。批量任务可以下载 ZIP，ZIP 中包含成功图片、`manifest.json` 和失败说明。

### 7.3 大图编辑

进入编辑状态后，可以点击文字区域，修改译文、移动文本框、拖动边缘调整大小、选择字体并查看字体预览。也可以新增文本框、删除误检区域、恢复原文，或使用手动画笔擦除并撤销。

### 7.4 专有名词库

进入侧边栏“专有名词库”，可以新增、修改、删除和搜索词条，也可以导入 JSON。词条记录源语言和目标语言，翻译时按语言方向使用。

## 8 常见问题

- **识别不完整：**检查图片清晰度；艺术字、低分辨率和复杂背景可能影响 OCR。
- **速度较慢：**首次运行需要加载模型，CPU 环境和 LaMa 修复耗时更长。
- **译文不理想：**可使用术语库、AI 润色或进入编辑器人工修改。
- **翻译服务失败：**检查网络和 API 配置，系统会按回退链继续尝试其他服务。
