# 项目介绍 PPT 与产品视频脚本

## 一、答辩 PPT（建议 7–8 分钟）

### 第 1 页：项目名称

漫画多语言智能翻译系统（ComicX）。展示学生信息和项目一句话定位。

### 第 2 页：问题与价值

国外漫画存在语言壁垒；人工翻译还要处理 OCR、擦除、修复和排版；通用翻译工具不能保证气泡结构和阅读体验。项目目标是用一个 Web 系统完成从图片到译图的闭环。

### 第 3 页：用户流程

上传/粘贴/文件夹导入 → 选择语言和润色风格 → 提交任务 → 查看逐图进度 → 预览 → 编辑/重试 → 单张下载或 ZIP 下载。

### 第 4 页：核心流水线

检测 → OCR → 擦除/修复 → 气泡分组 → 上下文翻译 → 质量检查 → 横竖排版输出。

### 第 5 页：技术架构

React/Vite 前端、FastAPI 后端、TranslationTaskManager 任务管理器、SQLite、本地文件存储，以及检测/OCR/修复/翻译/渲染可插拔引擎。

### 第 6 页：核心技术难点

- 同一气泡多行文本整体翻译；
- 清理图分组与原图轮廓双重边界判断；
- 多边形、笔画和注音联合掩膜；
- OpenCV/LaMa 局部背景修复；
- 中文横排/竖排和气泡内安全渲染；
- 失败回退、质量告警和批量串行推理。

### 第 7 页：产品交互

展示对话式任务流、侧边栏、进度、逐图预览、单张重试、字体选择、文本框拖拽和擦除撤销。

### 第 8 页：AI 协作

展示真实交互截图，说明学生如何提出约束、质疑 AI 方案、要求先读代码、进行构建/测试验证，并记录 AI 的能力边界。

### 第 9 页：演示结果

使用项目中的日文、英文和中文样例，分别展示原图、修复中间图和最终译图。演示单图、批量、术语库和编辑能力。

### 第 10 页：总结与展望

当前完成可运行 MVP 和阶段性验收闭环；后续优化 GPU/英文 OCR、历史任务、人工校对、更多翻译风格和质量评估。

## 二、产品视频脚本

### 片段 1：项目介绍（20 秒）

旁白：这是 ComicX 漫画多语言智能翻译系统，可以将日语或英语漫画图片自动转换为中文译图。

### 片段 2：上传任务（30 秒）

操作：粘贴一张图片或打开文件夹导入多张图片，选择自动检测到中文，选择自然或自定义润色风格并提交。

### 片段 3：处理过程（50 秒）

旁白：系统依次完成文字检测、OCR、原文擦除、背景修复、气泡分组、上下文翻译、质量检查和中文排版。批量任务逐图显示状态，单张完成即可预览。

### 片段 4：结果编辑（60 秒）

操作：打开大图预览，点击文字区域，修改译文，拖拽文本框，调整字体和字号，展示实时字体预览；用画笔擦除一处残留并点击撤销。

### 片段 5：术语库和下载（30 秒）

操作：新增一个角色名术语，回到任务中展示统一译法；点击单张下载或批量 ZIP 下载。

### 片段 6：总结（20 秒）

旁白：项目把漫画检测、OCR、图像修复、翻译和排版整合为一个可观察、可编辑、可扩展的 Web 流程。
