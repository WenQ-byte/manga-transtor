# 系统实现与测试报告

## 1 系统概述

系统名称：漫画多语言智能翻译系统（ComicX）。系统采用 React/Vite 前端和 FastAPI 后端，输入漫画图片，输出带有中文译文的 PNG 图片。默认检测/OCR 使用 MIT 路线，PaddleOCR 作为重要回退；图像修复使用 OpenCV，LaMa 为可选增强；翻译后端支持 DeepSeek、OpenAI、DeepL、Google 和 MyMemory。

## 2 功能实现

### 2.1 翻译任务

- 底部输入区支持单图、多图、粘贴图片和文件夹导入；
- 支持自动检测源语言和中文、日语、英语目标语言；
- 每张图片独立显示等待中、处理中、完成和失败状态；
- 完成后立即预览，支持单张下载、重新翻译和批量 ZIP 下载；
- 翻译任务和结果元数据保存在 SQLite，本地文件保存图片内容。

### 2.2 漫画图像流水线

```text
detect → ocr → inpaint → bubble grouping → translate → quality assessment → render
```

检测和 OCR 负责获得文字区域与识别文本；擦除阶段生成多边形、笔画和注音联合掩膜并修复背景；气泡分组使用清理图寻找内部区域，同时用原图轮廓防止跨气泡合并；翻译以气泡整体为单位；渲染阶段根据方向、气泡大小和目标语言进行横排/竖排布局。

### 2.3 翻译后编辑

- AI 润色：使用同一 DeepSeek 翻译服务，对已翻译文本进行自然、口语、热血、搞笑、正式或自定义风格润色；
- 文本编辑：修改单个文本区域译文并重新渲染；
- 文本框编辑：拖拽移动、调整大小、手动新增和删除文本框；
- 字体编辑：选择字体、预览字体、设置字号、字重、颜色和方向；
- 擦除工具：在大图预览中绘制掩膜，执行局部背景修复并支持撤销；
- 恢复原文：对误删文本区域恢复原始文字状态。

## 3 接口设计

| 方法 | 接口 | 作用 |
|---|---|---|
| POST | `/api/translate` | 创建单图翻译任务 |
| POST | `/api/translate/batch` | 创建批量子任务 |
| POST | `/api/translate/batch/status` | 查询批次汇总状态 |
| POST | `/api/translate/batch/zip` | 下载批量结果 ZIP |
| GET | `/api/translate/{id}/status` | 查询任务状态和诊断信息 |
| POST | `/api/translate/{id}/retry` | 失败任务重新创建 |
| POST | `/api/translate/{id}/polish` | AI 润色已有译文 |
| GET | `/api/translate/{id}/regions` | 获取编辑区域和字体选项 |
| POST | `/api/translate/{id}/edit` | 修改译文、位置和样式 |
| POST | `/api/translate/{id}/erase` | 提交手动画除掩膜 |
| POST | `/api/translate/{id}/erase/undo` | 撤销擦除 |
| POST/DELETE | `/api/translate/{id}/text-box` | 新增或删除文本框 |
| POST | `/api/translate/{id}/font-preview` | 生成字体预览 |
| GET | `/api/glossary` | 查询术语库 |
| POST/PUT/DELETE | `/api/glossary` | 维护术语词条 |

## 4 测试策略

测试使用 Python 标准库 `unittest`，不使用 pytest。测试重点包括：

- API 参数、文件格式、大小限制和语言校验；
- 单图/批量任务、失败隔离、ZIP 清单和重名文件；
- 任务串行执行和流水线锁；
- OCR 引擎回退、语言检测和低置信度处理；
- 气泡分组、原图边界否决和非气泡文字保留；
- 掩膜覆盖、注音扩展、OpenCV/LaMa 修复和残影处理；
- 横排、竖排、英文换行、中文列平衡和渲染安全边界；
- 术语库 CRUD、导入、重复词条和内置词条迁移；
- 翻译服务回退、上下文编号解析和质量警告。

执行命令：

```powershell
.venv\Scripts\python.exe backend\tests\test_app.py
```

## 5 部署说明

```powershell
.venv\Scripts\python.exe start.py
```

也可以分别启动：

```powershell
.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --app-dir backend
cd frontend
npm.cmd run dev
```

生产构建命令：`cd frontend; npm.cmd run build`。核心依赖、AI 依赖、LaMa 依赖和 MIT 依赖分别位于 `backend/requirements*.txt`。真实翻译服务需要在 `.env` 中配置 API；`.env` 不应提交到版本库。

## 6 安全与稳定性

- 上传前校验扩展名、空文件和大小；
- 文件名使用安全名称，ZIP 结果只解析服务端保存的安全相对路径；
- 批量任务编排与模型推理分离，模型推理保持单 Worker 串行；
- 通过多级气泡几何回退降低文字越界和覆盖人物的风险；
- 质量告警记录免费回退、译文过短、语言残留、数字/单位遗漏和术语遗漏。
