# 实训案例概览（重庆大学 · 18 个项目）

> 来源：`重庆大学项目表.md`。项目按难度系数分层，学生选题时参考。
> 技术栈提示：各项目含不同技术实现，但本实训统一以 **Python / C++** 为教学主线，AI 扩展功能可调用大模型 API。

## 难度系数 1.1（挑战级）

| 项目 | 技术栈提示 | 核心亮点 |
|------|------------|----------|
| 多模态中草药图像识别智能体 | CNN（ResNet/MobileNet）、图像分类 | 多标签标注 + 相似检索 + LLM 问答 |
| 漫画多语言智能翻译与图像合成系统 | 图像处理、OCR、翻译 API、inpainting | 语境感知翻译 + 排版修复 |
| 个性化有声读物智能生成系统 | TTS（PaddleSpeech）、音频处理 | 情感化多角色演绎 + 沉浸式剧场 |
| 独居老人安全检测与情感陪护系统 | OpenCV / 轻量模型、摄像头 | 异常行为识别 + LLM 情感陪护 |
| 基于程序化生成的 Roguelike 策略游戏 | 程序化生成、游戏逻辑 | LLM 动态叙事 + 自适应难度 |

## 难度系数 1.0（标准级）

| 项目 | 技术栈提示 | 核心亮点 |
|------|------------|----------|
| 智能营养膳食制作与推荐系统 | Web / 数据库 | 营养计算 + LLM 膳食顾问 |
| 公司 HR 制度智能问答系统 | RAG / 正则匹配 | 私有知识库问答 + 制度解读 |
| 人物疲劳监测摄像头 | OpenSeeFace、模型部署 | 实时疲劳监测 + 多级报警 |
| 仿网易云音乐播放器 app | 本地音乐 / ID3 / UI | 播放控制 + 歌词同步 + 频谱 |
| 企业 IM | Socket、即时通讯 | 点对点 / 群聊 / 文件传输 |
| 植物识别相机 | MobileNet / CNN | 私有模型 + 第三方模型融合 |
| AI 模拟面试官与职业规划系统 | LLM、职业测评 | 多轮面试 + 评估报告 |
| AI 手势游戏（横板射击 / 平台跳跃） | 神经网络 / scikit-learn、摄像头 | 手势识别控制游戏 |
| 基于树莓派的智能门神 | 树莓派、人脸识别、语音 | 硬件联动 + LLM 管家 |

## 难度系数 0.9（基础级）

| 项目 | 技术栈提示 | 核心亮点 |
|------|------------|----------|
| 网络监控系统 | Socket、进程 / 硬件信息 | 远程监控 + 进程控制 |
| 文件下载系统 | Socket、多线程、断点续传 | 分片校验 + 智能策略 |
| 行程记录系统 | EXIF / GPS、地图 | 轨迹可视化 + 游记生成 |
| 招聘网站数据分析 | Requests / Pandas / BeautifulSoup / Matplotlib（Python）| 爬虫 + 清洗 + 可视化 |

## 选题建议

- 基础级适合刚入门、希望先把流程跑通的同学；
- 标准级覆盖主流应用类型，综合性强；
- 挑战级对算法 / 模型训练要求高，建议有一定基础或组队选择；
- 难度系数直接影响最终成绩（答辩 60 分 × 难度系数）。
