# 基础环境指导手册（重庆大学 · Python / C++ 方向）

> 适配 AI4SE 实训一。本实训以 **Python 与 C++ 双轨** 为主，AI 协作通过 OpenCode + 大模型完成。
> 原始详细手册见 `实训知识库/raw/基础环境指导手册.html`。

## 一、总体环境清单

| 类别 | 工具 / 版本 |
|------|-------------|
| 操作系统 | Windows（推荐 WSL2）/ macOS / Linux |
| Python 方向 | Python 3.x、pip、IDE（VS Code / PyCharm）|
| C++ 方向 | C++ 编译器（MSVC / g++ / Clang）、CMake、IDE |
| AI 编程工具 | OpenCode（开源 AI 编码助手）|
| 大模型 | Qwen / DeepSeek / GLM 等 |
| 可选数据库 | SQLite / PostgreSQL（项目需要时使用）|

## 二、Python 方向环境

1. 安装 Python 3.x，勾选「Add to PATH」；
2. 验证：`python --version` / `pip --version`；
3. 常用库按需安装：`pip install requests pandas beautifulsoup4 matplotlib numpy opencv-python`；
4. 配置 IDE（VS Code 安装 Python 插件 / PyCharm）；
5. 安装并配置 OpenCode，接入所选大模型 API。

## 三、C++ 方向环境

1. Windows：安装 Visual Studio（含「使用 C++ 的桌面开发」工作负载）或 MinGW-w64；
   Linux/macOS：安装 g++ / Clang（`g++ --version` 验证）；
2. 安装 CMake（项目构建需要）；
3. 配置 IDE（VS Code 安装 C/C++ 插件，或 Visual Studio / CLion）；
4. GUI 方向可引入轻量 GUI 库（如 Qt / wxWidgets，按项目要求）；
5. 安装并配置 OpenCode，接入所选大模型 API。

## 四、AI 工具链（OpenCode + 大模型）

- OpenCode 是开源 AI 编码助手，用于 VibeCoding、代码理解与迭代；
- 首次使用需配置大模型 API Key（Qwen / DeepSeek / GLM 等任选）；
- 提示词工程是本实训重点，参见 `references/training-schedule.md` 线上第 2 周内容。

## 五、常见问题

- **Python 命令找不到**：检查 PATH 是否包含 Python 安装目录；
- **pip 安装慢 / 超时**：可切换到国内镜像源；
- **OpenCode 无法连接模型**：检查 API Key 与网络，确认模型服务可用；
- **C++ 编译报错**：确认编译器已安装且加入 PATH，`g++ --version` 验证。

> 环境搭建是第一周线上任务，遇到卡点及时在答疑时间（每周二、四晚）提问，或向 AI 导师描述具体报错信息。
